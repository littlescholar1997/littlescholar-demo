# 小學者美語：設計健檢與新初版

日期：2026-11-17

## 目前網站的主要問題

| 問題 | 影響 | 本次處理 |
| --- | --- | --- |
| 超大字與紅色矩形主導首頁 | 看不出閱讀教學及陪伴感 | 以原官網閱讀照片搭配適中標題，保留紅色為品牌與行動色 |
| 分隔線、左右欄與文字橫列重複 | 長頁缺少節奏 | 教學理念採閱讀歷程，課程採可切換年段，文章用圖文，見證完整展開 |

| 課程內容需連續閱讀全部文字 | 手機掃讀負擔 | 國小／國中／高中分頁，支援點擊與鍵盤方向鍵，無 JS 時仍顯示內容 |
| 手機聯繫入口位於頁尾 | 需要較多捲動 | 加入底部來電入口，保留安全區與頁尾空間 |
| 動態效果分散且不對應操作 | 增加制式 landing page 感 | 僅首頁一次進場，互動回饋以選單、分頁與連結為主 |

## 新設計方向

「閱讀與陪伴」：像走進一間認真選書、願意聽孩子說話的社區美語學校。

- 品牌紅 #BC000B：主要行動與品牌辨識。
- 深墨綠 #272C29：文字。
- 白 #FFFFFF：主要背景。
- 淡綠 #EDF2E9：閱讀照片與見證區背景。
- 書頁黃 #F4D36B：課程書本視覺。
- Noto Sans TC：標題與內文使用一致字族，以字級與粗細建立層級。
- 所有內容沿同一最大寬 1200px 容器對齊；手機保留 20px 邊距。
- 主要按鈕 44–48px 以上，保留鍵盤焦點與減少動態設定。

檢討：避免以奶油底加襯線字，或大批相同圓角卡片取代舊版。改以閱讀照片作為首頁重點，書本只用於具教學意義的課程區。圓角用於照片、區域容器，見證仍為容易閱讀的完整文字。
